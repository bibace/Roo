# ADR 0011: On-Demand AWS Console Context Detection

## Status

Superseded

Superseded by ADR 0014.

## Context

Organization Mode needs the user's current AWS Console context without turning
Roo into an AWS client or granting persistent access to AWS pages.

This ADR supersedes only the page-inspection and extension-permission portions
of ADR 0004. It preserves ADR 0004's credential-free and no-network decisions.

## Decision

Roo uses `activeTab` + `scripting` only after explicit extension invocation.
The generated manifests request exactly `storage`, `activeTab`, and `scripting`.
Roo has no persistent AWS host permissions, no static content scripts, and no
runtime-registered content scripts.

The read path is:

```text
active/current-window tab
        ↓
strict commercial AWS Console URL allowlist
        ↓
one-shot argument-free MAIN-world reader
        ↓ execution failure only
one ISOLATED-world fallback
        ↓
sanitized account context result
```

The MAIN-world code receives no extension-private data. Returned data contains
only sanitized AWS account identity fields, a multi-session boolean, and a
source marker. Roo never reads usernames, cookies, tokens, credentials, CSRF
data, SAML/OIDC data, or AWS API responses. The reader makes no network
request, and the context result is not persisted as AWS identity.

The URL allowlist accepts only HTTPS `console.aws.amazon.com` and its
dot-boundary subdomains, `health.aws.amazon.com`, and `lightsail.aws.amazon.com`.
Host comparison is case-insensitive and URL credentials are rejected. GovCloud,
China, and EU Sovereign hosts are unsupported. An unsupported or non-AWS tab
displays `Open Roo from a supported AWS Console tab.`, disables Search, and
shows zero accounts, roles, and result rows.

Organization Mode consumes this boundary during explicit Popup invocation.
Fresh page context is authoritative and active organization is tab-scoped.
Base-login evidence precedes current-account evidence; conflicting evidence
fails closed. Simple Mode remains independent of context detection.
The fallback cache is browser session state only and contains catalog version
and organization ID, never AWS identity.

## Consequences

Roo's explicit Popup invocation is aware of the active AWS Console account while
retaining a narrow, one-shot permission boundary. Invalid URLs, execution
failures, and malformed page results remain unavailable states. The
browser-specific manifest differences continue to be generated by WXT; Firefox
remains MV2 with the fixed Gecko identity, desktop minimum 140.0, and generated
Android minimum 142.0.
